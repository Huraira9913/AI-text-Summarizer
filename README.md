# House of Wisdom – AI Text Summarizer

AI-powered text summarizer built with Python and Flask. It condenses long documents, articles, or paragraphs into concise summaries.

## Features

- Instant text summarization
- Simple web interface
- Handles reasonably large text inputs
- Useful for students, researchers, and professionals

## Tech Stack

- **Backend**: Python, Flask
- **NLP**: NLTK / Transformers (depending on implementation)
- **Frontend**: HTML, CSS, Bootstrap

## Project Structure

```
AI-text-Summarizer/
├── app.py              # Flask application
├── text_summary.py     # Summarization logic
├── index.html          # Frontend
└── README.md
```

## Setup & Run

```bash
pip install flask nltk
# or the specific NLP libraries used in text_summary.py

python app.py
```

Open the local URL shown in the terminal (usually http://127.0.0.1:5000).

## Usage

1. Paste or type the text you want to summarize.
2. Click **Summarize**.
3. View the generated summary.
