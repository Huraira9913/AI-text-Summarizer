House of Wisdom – AI Text Summarizer
House of Wisdom is an AI-powered Text Summarizer built using NLP and Flask.
It condenses long documents, articles, or paragraphs into concise summaries, helping users save time and extract key information effortlessly.

Features
1)Summarizes text instantly
2)User-friendly web interface powered by Flask
3)Built with Python NLP libraries for accurate results
4)Handles large text inputs efficiently
5)Ideal for students, researchers, and professionals

Tech Stack
1)Backend: Python, Flask
2)NLP Libraries: NLTK, SpaCy, Transformers
3)Frontend: HTML, CSS, Bootstrap

Usage
1)Enter or paste your text in the input box
2)Click Summarize
3)Get a clear, concise summary instantly

About
Inspired by the historic House of Wisdom – bringing centuries of knowledge into a compact AI-powered summary.
